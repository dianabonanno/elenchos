# Elenchos — Socrates' Way (La Via Socratica)

Gioco educativo di filosofia, a giocatore singolo (circa 10 minuti), in pixel-art. Progetto universitario.

> Atene, 399 a.C., cinque giorni prima del processo a Socrate. Un giovane filosofo, guidato dalle domande di Socrate, raccoglie tre frammenti degli appunti di Platone per convincerlo a chiedere l'esilio. Non serve sapere di filosofia: basta ascoltare.

**Gioca online:** https://dianabonanno.github.io/elenchos/

In locale: apri `index.html` in un browser moderno (nessuna installazione). Frecce o WASD per muoverti, Spazio/Invio per avanzare nei dialoghi.
